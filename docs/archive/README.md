# Archived documentation

These documents describe the original MERN prototype (MongoDB/Mongoose, JWT, role and rank
middleware). They are kept for history only and do not describe current behavior. The
current application uses PostgreSQL (ADR-0003) and HttpOnly cookie sessions with CSRF
(ADR-0001); see [API documentation](../API_DOCUMENTATION.md), [HANDOVER](../HANDOVER.md)
and the root [CONTRIBUTING](../../CONTRIBUTING.md).
